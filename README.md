<br/>

Architected an automated task-management pipeline using FastAPI and LangGraph with **7 specialized agents** to ingest, extract, embed, deduplicate, and prioritize tasks from GitHub, Gmail, and Slack.

| Aspect | Detail |
|---|---|
| **Stack** | TypeScript, React, NestJS, Python, FastAPI, LangGraph, PostgreSQL (pgvector), RabbitMQ, Redis, Docker |
| **Scale** | 7-agent coordinated pipeline across 3 data sources |
| **Reliability** | Redis-backed state management, circuit breakers, rate limiting, Dead Letter Queues (DLQs) |
| **Observability** | Docker-deployed microservices with Prometheus, Grafana, and OpenTelemetry telemetry |
| **Impact** | Low-latency semantic search via pgvector-backed embeddings |

Engineered a modular NestJS backend integrated with PostgreSQL and pgvector for low-latency semantic search, using RabbitMQ for asynchronous event messaging.

</details>

|---|---|
